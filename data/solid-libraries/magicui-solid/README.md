# MagicUI Solid source previews

All **76 documented components** are individually verified and indexed from `axuj/magicui-solid` revision `3100c2f704620f96dc431dd86f86bbbf9bb05965`, checked on 2026-10-30. All **76 previews** have been checked in both themes. `coverage.json` lists exact names, official URLs and preview status. `page-verification.json` records every HTTP-200 page and hash.

The real Solid port and official demo modules compile with Solid 1.9.17 and babel-preset-solid 1.9.16. Tailwind 4.3.3 compiles the original global CSS, utility classes and keyframes. Published demos inherit Starlight Black's theme and typography, including the exact Geist Sans font; those original inputs and notices are retained. The renderer's theme sets the original `data-theme` selector. Registry installation defaults are distinct from this published docs context.

The original three direct entries remain byte-identical after lossless Brotli unpacking. `baseline.json` authenticates the decoded artifact and its retained lock; direct records remain in `build.json`. The expansion stores shared CSS plus 73 additional entries. `data/component-previews/solid/magicui-solid/index.ts` default-exports the combined artifact and separate components, media, highlighting and Tweet Card groups. Highlighting uses lossless Brotli JSON packing, with both decoded-content and packed-file hashes recorded. Every closed group dispatches the selected demo through lexical `PREVIEW_COMPONENT`. Each new file is below 5 MB.

Code Comparison uses Shiki's official fine-grained API with the original TypeScript grammar, GitHub themes and notation transformers. `shiki-verification.json` confirms byte-identical generated HTML against the full bundle for both panels and themes. Only unrelated grammars are omitted.

Licensed generated avatar PNGs, Simple Icons, country flags and the Geist font retain their captured bytes and attribution. The Lens and Pixel Image photographs use disclosed WebP derivatives stored once in `assets.json`: Lens changes from 398,795 to 128,990 bytes (2071 to 1600 pixels wide); Pixel Image changes from 900,059 to 121,382 bytes (1920×1920 to 800×800). Original and delivered hashes, sizes and permissions are retained. Comparison against the originals preserves framing and color, with expected fine-detail softening. Neither derivative is described as original bytes.

GitHub profile photos and Hero Video posters have no verified redistribution permission: their original URLs remain blocked, with explicit limitations. Hero Video Dialog still opens and closes, while its YouTube embed requires external access. Tweet Card mounts the original `MagicTweet` export and stylesheet with clearly labeled sample text, a generated avatar and the licensed Backlight video excerpt. The video reserves its 16:9 dimensions while loading. It does not fetch the official live post. The example bypasses `ClientTweetCard`'s loading and error states; links inside the card cannot open in the sandbox.

Video Text reuses the exact 722,190-byte original ocean WebM already retained for React Magic UI. `ocean-permission.json` records identical hashes for Magic UI's video and the CodePen-hosted copy, the uploader's public Pen and user ID, and CodePen's user-content grant. CodePen's terms rely on the uploader's warranty of authority; the person who filmed the footage was not independently identified. The original bytes, including the muted audio track and loop timing, are unchanged and no new video file is committed.

Backlight is a **lossy 2-second excerpt from source seconds 3–5**, converted from 2560×1440/50fps to 720p H.264/30fps without audio. Original: 43,852,026 bytes; delivered: 392,139 bytes. Both hashes and the transformation are in `resource-media.json`. The binary lives in `data/component-previews/media/`; the compiled component keeps its original URL, relocated by Col's existing bounded MCP resource loader. MCP Apps uses resource reads; standalone HTML inlines the same verified excerpt because it fits the renderer's media budget. No video bytes are duplicated in executable source or the Solid entry's inline assets. Delivered video bytes are not called original.

Each preview's compact `assets` list includes only its actual inline assets and shared font: original/download/resolved URLs, SHA-256, bytes, MIME type and attribution. Shared image/media disclosures are supplied by Col's existing asset loader. `build.json` records the dynamic URL compilation adaptation needed to prevent Solid from folding these URLs into static templates. Simple Icons' pinned CC0 notice is retained and grants no trademark rights. The port declares MIT in README, but its linked LICENSE is absent at the pinned revision and its retained README provides no copyright notice; the missing license is exposed in every preview and both gaps appear in the bundled notice. Original Magic UI, Starlight, Geist, avatar-generator and dependency notices are retained.

`catalog.json` supplies website metadata; `corpus.json` contains scoped props/examples and official setup links without executable installation commands. `browser-verification.json` records light/dark sandbox mounts, visible text, animations, media, controls and disposal. Network-dependent limitations are disclosed without invented content; shared MCP tests cover transport/widget delivery separately.

`dependencies.json` follows each component's own source graph and the official registry, including its theme dependency, and separately records selected-demo requirements. Public MCP dependencies include their verified union. Theme Toggler uses its original controlled API because persistence is unavailable in the sandbox; Blur Fade uses the official text demo; the published `/magicui-solid/` base path is substituted from the pinned deploy configuration. `media-browser-verification.json` separately checks the actual standalone `render_component` output, Lens hover/Escape, WebP decoding and Backlight playback.
