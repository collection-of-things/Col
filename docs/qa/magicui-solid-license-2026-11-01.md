# MagicUI Solid license research

Checked on 2026-11-01 against the upstream repositories, their GitHub APIs, and Col's retained preview notices.

- Col pins MagicUI Solid at [`3100c2f704620f96dc431dd86f86bbbf9bb05965`](https://github.com/axuj/magicui-solid/tree/3100c2f704620f96dc431dd86f86bbbf9bb05965), which was also upstream's `master` head at this check. The port's [README](https://github.com/axuj/magicui-solid/blob/3100c2f704620f96dc431dd86f86bbbf9bb05965/README.md) explicitly says it is licensed under MIT and identifies the project as a Solid port of Magic UI. That MIT statement was added in [this 2026-08-09 README change](https://github.com/axuj/magicui-solid/commit/b1df01b7fb8894a13bbb0bec63f265e43ee7cd5f).
- The README links to a `main/LICENSE` file, but the [complete pinned source tree](https://api.github.com/repos/axuj/magicui-solid/git/trees/3100c2f704620f96dc431dd86f86bbbf9bb05965?recursive=1) contains no file named LICENSE, LICENCE, NOTICE, or COPYRIGHT. GitHub's [repository metadata](https://api.github.com/repos/axuj/magicui-solid) reports no detected license. GitHub's [license documentation](https://docs.github.com/en/rest/licenses/licenses) says that its detector does not account for license statements in documentation; its null result therefore does not erase the README statement.
- No separate copyright holder for the Solid port was identified in its README, source search, [package metadata](https://github.com/axuj/magicui-solid/blob/3100c2f704620f96dc431dd86f86bbbf9bb05965/package.json), or [published issue history](https://github.com/axuj/magicui-solid/issues). A repository owner or commit author is not, by itself, an identified copyright holder. Obtaining an explicit notice or clarification from the port's rights holder would resolve that gap.
- The separate original React project supplies an [MIT license naming “Copyright (c) Magic UI”](https://github.com/magicuidesign/magicui/blob/bca54ab2730216c91e3a732f2af08e49c7ddebd4/LICENSE.md). That notice identifies the original project's holder; it does not establish who owns the Solid-specific changes or the rights to third-party demo assets. Col's retained Solid preview notice includes the original Magic UI license and separately discloses the missing port license file and copyright notice.

These findings document the available evidence; they do not determine ownership or give a legal opinion on redistribution. Preview code, styling, and sandbox were not changed for this research.
